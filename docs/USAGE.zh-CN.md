# 使用说明

## 首次启动

Windows 11 和大多数 Windows 10 电脑已安装 Microsoft Edge WebView2 Runtime，可直接运行 EXE，无需另装 .NET。v0.5.11 起，缺少 WebView2 时软件会显示「首次运行准备」，点击「一键安装并继续」后联网下载微软官方小型安装器，验证微软数字签名，再安装运行时。检测安装成功后自动进入软件。

下载阶段可以取消。开始安装后请等待完成；失败时可重试或点击「手动下载」前往微软官网。离线电脑可先从微软官网获取 Evergreen Standalone Installer，再手动安装。软件不会要求关闭安全软件或绕过证书验证。

## 登录和升级

程序通过 Microsoft Edge WebView2 打开 BOOTH / pixiv 官方登录页面。请在官方页面完成密码、二步验证或验证码。程序不会要求把密码粘贴到软件设置，也不会读取你在 Edge 中的个人浏览器配置。

设置中的「保留登录」默认开启。软件使用固定数据目录与当前 Windows 用户的加密会话备份保存登录状态。升级时退出旧版（包括托盘中的进程），把新版解压到自己的程序目录再启动，保留 `%LOCALAPPDATA%\BOOTH-Shelf` 即可。Cookie 被网站撤销、过期或要求重新验证时，仍需重新登录。

资料库、设置、下载索引等均在 `%LOCALAPPDATA%\BOOTH-Shelf`，该目录不适合公开分享。「导出 JSON」导出的是资产资料库，不包含完整浏览器会话，也不是全部设置的备份。

v0.5.13 起，启动时及运行中每 6 小时检查本项目的 GitHub Releases（包含预览版），设置的「软件更新」也可手动检查。发现新版后点击「下载并重启」，程序会下载更新包、核对 SHA-256 和版本，退出后替换当前 EXE 并重新打开。下载期间可以取消；同步或资产下载进行中不会自动重启，处理完任务后再点击「重启并安装更新」。更新保留现有数据目录与登录备份，GitHub 检查不发送 BOOTH 账号数据。

v0.5.12 及更早版本需要手动升级一次到 v1.0.0 或更新版本才能使用此功能。请从 ZIP 解压到可写文件夹后运行；程序目录不可写时会提示移动目录，不会申请管理员权限。更新失败保留旧版，启动失败尝试恢复旧版。当前软件仍未签名，Windows SmartScreen 可能提示「Windows 已保护你的电脑」；自动更新不会关闭或绕过系统安全检查。

目前单个数据目录仅适合一个 BOOTH 账号。若要使用另一账号，请建立独立目录并通过命令行启动，例如：

```powershell
.\BOOTH-Shelf.exe --data-dir "$env:LOCALAPPDATA\BOOTH-Shelf-SecondAccount"
```

## 同步和筛选

首次选择「全局同步」。全局同步扫描三个来源并补全标签、商品元数据和订单金额；大资料库初次同步仍需要时间。「快速更新」从各来源首页开始，找到已收录的边界后停止，优先获取新增资产。中途暂停保留已完成进度。网络限流时应等待软件提示的重试时间。

标签默认显示搜索、收藏和展开入口。直接点击标签表示必须包含；「任一」组中的标签满足一个即可；「排除」组不允许出现。三组条件同时生效。星标收藏标签，保存预设可下次一键应用。商品价格和标签不一定能覆盖已下架或不可访问的商品。

## 下载和本地库

已购、礼物卡片的下载按钮会列出有权限下载的文件，可多选并调整保存目录。免费来源只展示商品，不提供软件内下载按钮；从商品网页获取文件。

每个资产放在下载根目录下的 `商品ID_商品标题` 文件夹内。本地库显示由本软件记录且仍存在的下载文件。点击资产查看文件，点击文件打开；右键文件可定位目录或移到回收站。

右键本地资产卡片可以打开商品网页，或删除整个资产文件夹。删除前会列出目录；目录内自行解压或添加的文件也会一起移到回收站。如果同一资产曾下载到多个位置，确认框会列出这些目录。正在下载、包含其他资产或包含目录链接时会阻止整目录删除，请先处理相应情况。软件不会自动导入其他下载管理器的本地库。

## 更新提醒

在设置开启「资产更新通知」，左侧「通知」查看列表。只提醒本软件已下载且本地库中仍有文件的资产；未下载、下载失败或已删除全部本地文件的资产不提醒。本地库为空时不发送更新检查请求。默认每小时检查，可在设置选择 30 分钟、1／3／6／24 小时。主同步空闲且登录有效时增量检查；托盘运行继续，退出后停止。首次启用不回溯全部历史变化，新加入的资产先建立基线。

同步、订单、商品信息、通知检查及下载入口共用请求限速。遇到 HTTP 403、429 或网页验证时暂停自动访问，并保存暂停状态；重启不会自动解除。在设置的「BOOTH 访问」查看提示，必要时打开官方网页确认，等待提示时间结束后点击「继续访问」。同步选择原模式可续传。此限制用于降低负载，不代表 BOOTH 官方授权或保证不会触发访问限制。

Windows 的通知设置或勿扰模式可能隐藏托盘气泡，此时可在软件内查看。商品下架、私密、版本无法唯一识别，或 BOOTH 排序和公开元数据发生变化时，可能无法检测全部更新。通知不会自动下载文件。

## 金额、汇率和托盘

金额依据可读取订单中的商品金额（含 BOOST）统计。币种换算使用最新可用参考汇率，不是历史结算汇率。每次启动和运行中的本地时间零点自动更新汇率；离线保留上次缓存。

关闭窗口时可以选择缩小到托盘或退出。勾选「不再提示」后记住本次选择；在设置的「关闭主窗口时」可随时修改。双击托盘图标恢复窗口，托盘右键「退出程序」才会完全退出。
